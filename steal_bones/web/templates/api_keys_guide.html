Ключи API

Как получить доступ к каждому источнику. Сгруппировано по тому, нужна ли вообще регистрация.

Без ключа вообще — сразу работает

Magic Eden Ключ не нужен▶

Публичное чтение бесплатно: 120 запросов/мин для Solana, 30 запросов/мин для Bitcoin Ordinals/Runes. Ничего настраивать не нужно, адаптер работает из коробки.

Solana RPC (баланс) Ключ не нужен▶

Используется публичная нода api.mainnet-beta.solana.com, метод getBalance. Ничего получать не нужно. Если нужен более высокий лимит — заведите бесплатный ключ Helius (см. группу ниже), тогда адаптер сам переключится на него.

mempool.space (баланс Bitcoin) Ключ не нужен▶

Публичный REST API без регистрации и без строгого документированного лимита.

Ethereum / BNB / Base / Arbitrum / Polygon / Avalanche (баланс) Ключ не нужен▶

Баланс проверяется методом eth_getBalance через официальные публичные RPC каждой сети — регистрация не требуется. Ключ Etherscan V2 (группа ниже) нужен только для ДОПОЛНИТЕЛЬНЫХ данных сверх баланса.

Sui RPC (баланс) Ключ не нужен▶

Публичная fullnode-нода, метод suix_getBalance. Для дополнительных данных — Blockberry (группа ниже).

Нужна бесплатная регистрация

Etherscan API V2 Нужен ключ▶
  1. Зарегистрироваться на etherscan.io (email + пароль), подтвердить почту.
  2. В личном кабинете открыть раздел API Keys → Add.
  3. Скопировать сгенерированный ключ.
  4. Один и тот же ключ работает на 6 сетях сразу (Ethereum/BNB/Base/Arbitrum/Polygon/Avalanche) через параметр chainid.

Free-тир: 3 запроса/сек, 100 000/день. Часть высоконагруженных сетей может периодически выводиться из free-тира — сверяйте docs.etherscan.io/supported-chains перед стартом. Можно указать несколько ключей через запятую в Настройках — включится ротация (раздел 7.1).

OpenSea Нужен ключ▶

Быстрый вариант: POST-запрос на api.opensea.io/api/v2/auth/keys без регистрации — вернёт временный ключ на 30 дней (лимит ниже, ~60 запросов/мин на чтение).

Постоянный вариант:

  1. Зарегистрироваться на opensea.io.
  2. Перейти в Settings → Developer.
  3. Заполнить форму запроса ключа.
  4. Дождаться одобрения (обычно несколько дней).
Tensor Нужен ключ▶
  1. Открыть раздел «API & SDK» в docs.tensor.trade.
  2. Заполнить форму запроса доступа (описание проекта).
  3. Дождаться ответа с ключом на почту.

Доступ не самостоятельный — по заявке. Точный GraphQL-запрос для ленты продаж коллекции стоит свериться с документацией, которую пришлют вместе с одобрением (см. TODO в adapters/marketplaces/tensor.py).

Rarible Нужен ключ▶
  1. Зайти на rarible.org → «Get Started».
  2. Зарегистрироваться, выбрать бесплатный план Starter.
  3. В личном кабинете → «API Keys» → «Create Your API Keys».
  4. Использовать mainnet-ключ в заголовке X-API-KEY.
LooksRare Нужен ключ▶
  1. Вступить в Developer Discord LooksRare (ссылка в looksrare.dev).
  2. Открыть тикет с запросом API-ключа.

Ключ нужен только для mainnet-запросов (тестовая сеть Sepolia работает без ключа). Лимит — 120 запросов/мин.

Helius Нужен ключ▶
  1. Зарегистрироваться на helius.dev (email/Google/GitHub).
  2. Выбрать план Free (без карты).
  3. В дашборде сгенерировать ключ.

Используется как замена Solscan для дополнительных данных по Solana (токены/NFT на балансе, история) — на момент подготовки этого проекта у Solscan Pro API больше не было самостоятельного бесплатного тарифа (только платная подписка), поэтому основной баланс идёт через RPC, а Helius — для всего остального.

TronGrid Нужен ключ (для повышенного лимита)▶
  1. Зарегистрироваться на trongrid.io по email.
  2. Подтвердить аккаунт по ссылке из письма.
  3. В личном кабинете — «Create API Key».
  4. Использовать в заголовке TRON-PRO-API-KEY.

Базовые запросы проходят и без ключа — регистрация повышает лимит.

Xverse API (Bitcoin Ordinals/Runes) Нужен ключ▶

Ранее для Ordinals/Runes рекомендовался Hiro Ordinals API, но он выведен из эксплуатации (март 2026) в пользу Xverse. Получить ключ (заголовок x-api-key) — через портал разработчика на docs.xverse.app. Если нужен именно Hiro (для данных Stacks) — бесплатный ключ там тоже выдаётся сразу после регистрации на hiro.so.

Blockberry (Sui) Нужен ключ▶
  1. Зарегистрироваться в API User Portal на docs.blockberry.one.
  2. Ключ генерируется автоматически при создании аккаунта.

Бесплатный план по умолчанию — до 3 ключей на аккаунт.

Birdeye Нужен ключ▶
  1. Зарегистрироваться на bds.birdeye.so.
  2. Выбрать Free-план (≈30 000 compute units/месяц).
  3. Сгенерировать ключ в личном кабинете.

Основной источник кошельков-трейдеров для мемкоинов (DexScreener этого не умеет — см. вкладку и комментарий в dexscreener.py).

Особый случай

Blur Официального API нет▶

Blur не публикует официальный публичный API для сторонних разработчиков. Легальный путь — подключить агрегатор, который уже декодирует её сделки через свой официальный ключ (например Bitquery, бесплатная регистрация на ide.bitquery.io), и написать отдельный адаптер поверх него. Прямая интеграция потребовала бы неофициальных обходных путей — сознательно не реализовано.
